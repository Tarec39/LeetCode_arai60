## ステップ1

```python3
class Solution:
    def reverseList(self, head: ListNode | None) -> ListNode | None:
        pile_up_node = []
        while head:
            pile_up_node.append(head)
            head = head.next
        
        dummy = ListNode()
        node = dummy
        while pile_up_node:
            node_temp = pile_up_node.pop()
            node.next = node_temp
            node = node.next

        node.next = None
        return dummy.next
```

- 積み上げて、下ろして、つなぎなおす
- この問題がArai60のStackカテゴリにあったからStackの発想ができた。
- 最後の```node = node.next```はどうにか省略できないだろうか？これがないとテストで無限ループしてしまう。
- 変数名もどうにかしたい。
  - pile_up_nodeは、イメージをそのまま名前にしただけ。でも、もうちょっとあるだろう。
  - node_tempは考え込まないようにその場で適当に考えた。ダメな気がする。
