## 第一段階
#### ハッシュテーブルの解法
```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
        
        seen = set()
        node = head

        while node is not None:
            if node in seen:
                return node
            
            seen.add(node)
            node = node.next
        
        return None
```

#### ウサギとカメの解法
二つのポインターを違う速度で進めて一致したあとに、今度は連結リストの先頭にポインターを置いて、slowポインターと同じ速度で進めて一致したところが答えになる。
不思議だなあくらいに思ってる。
```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
        
        slow, fast = head, head

        while fast is not None and fast.next is not None:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                # ここより下は何度か答えを見た
                start = head

                while start != slow:
                    start = start.next
                    slow = slow.next
                
                return start
        
        return None
```

#### ウサギとカメの解法
```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
        
        slow, fast = head, head

        while fast is not None and fast.next is not None:
            slow = slow.next
            fast = fast.next.next
        # whileの中にwhileがあるのは好きじゃないので、外に出した。
            if slow == fast:
                break
        
        if fast is None or fast.next is None:
            return None

        # ポインタの違いが歩数ではなく開始地点になったから変数名を変えた。余分？
        start = head
        meeting = slow

        while start != meeting:
            start = start.next
            meeting = meeting.next

        # ここも変えたい衝動にかられたが、それは過剰な気がする。
        return start
```
