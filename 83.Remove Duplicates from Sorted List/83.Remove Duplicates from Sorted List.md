## 第一段階
#### 2ポインターの解法
```python3
class Solution:
    def deleteDuplicates(self, head: ListNode | None) -> ListNode | None:
        if head is None:
            return None
        
        node = head
        while node is not None:
            if node.val = node.next.val:
                node.next = node.next.next    
            node = node.next
    
        return head
```
#### ハッシュテーブルとダミーノード
ひねり出した感じがある
最初は紙の上でこう考えた：処理しているこのノードの値がすでに記録されている場合、そのノードを削除する。

しかしノードの削除の仕方がわからなかったのでコードに落とせなかった。

今回のコードは前の考えをひっくり返した：このノードの値が記録されていない場合、そのノードを追加する。

ダミーノードは、連結リストの先頭を触りたくないときに使うと読んだが、自分の中では連結リストを再構成するときに使うものと理解している。

```python3
class Solution:
    def deleteDuplicates(self, head: ListNode | None) -> ListNode | None:
        if head is None:
            return None

        seen = set()
        
        node = head
        new_head = ListNode(None)
        new_node = new_head
        
        while node is not None:
            if node.val not in seen:
                new_node.next = node
                new_node = new_node.next
            
            seen.add(node.val)
            node = node.next

        new_node.next = None
        
        return new_head.next
```

#### 再帰の解法

```python3
class Solution:
    def deleteDuplicates(self, head: ListNode | None) -> ListNode | None:
        if not head or not head.next:
            return head

        if head.val == head.next.val:
            return self.deleteDuplicates(head.next)

        head.next = self.deleteDuplicates(head.next)
        return head
```
