## 第一段階
#### ハッシュテーブルの解法
こっちの方が好き。点検表を片手に記録して、都度ダブりの有無を確認するイメージ。
```python
class Solution(object):
    def hasCycle(self, head):
        """
        :type head: ListNode
        :rtype: bool
        """
        seen = set()
        
        while head is not None:
            if head in seen:
                return True
            
            seen.add(head)
            head = head.next
        
        return False
```

#### ウサギとカメの解法
```python
class Solution(object):
    def hasCycle(self, head):
        """
        :type head: ListNode
        :rtype: bool
        """
        # 遅い方が先に来て、早い方が後の方がいいと思ってこの並び。
        slow = head
        fast = head

        # 曖昧な記憶でやってみた。テストケース通ってしまった。
        while fast.next is not None and fast.next.next is not None:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                return True
        
        return False
```

## 第二段階
#### ハッシュテーブルの解法
```python
class Solution(object):
    def hasCycle(self, head):
        """
        :type head: ListNode
        :rtype: bool
        """
        # 「こういうの」を全く考慮してなかった＝境界値
        if head is None:
            return False
    
        seen = set()
        # headは連結リストの先頭を指すものだから動くのは変だ、とコメントを見て納得。
        node = head

        while node is not None:
            if node in seen:
                return True
            
            seen.add(node)
            node = node.next
        
        return False
```
